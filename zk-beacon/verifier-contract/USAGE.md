# ZK Beacon Chain Verifier Contracts Usage Guide

## Contracts Overview

### 1. ScUpdateVerifier (SCUpdator.sol)
Groth16 proof verifier generated by gnark.

### 2. SyncCommitteeManager
Manages sync committee updates with ZK proof verification.

## Contract Deployment

```solidity
// 1. Deploy ScUpdateVerifier
ScUpdateVerifier verifier = new ScUpdateVerifier();

// 2. Prepare genesis pubkeys (512 × 48 bytes)
bytes[] memory genesisPubkeys = new bytes[](512);
// ... fill with actual pubkeys ...

// 3. Deploy Manager
SyncCommitteeManager manager = new SyncCommitteeManager(
    0,                    // genesis period
    genesisPubkeys,       // genesis sync committee
    address(verifier)     // verifier address
);
```

## Public Inputs Structure (44 values)

```
input[0..11]:   AggregatedPubKey (12 limbs)
  ├─ [0..5]:    X coordinate (6 limbs)
  └─ [6..11]:   Y coordinate (6 limbs)

input[12..43]:  NextSyncCommitteeRoot (32 bytes)
  └─ [12..43]:  Each element = 1 byte
```

## Update Sync Committee

```solidity
manager.updateSyncCommittee(
    proof,              // [8]uint256 - Groth16 proof
    [0, 0],            // [2]uint256 - commitments (not used)
    [0, 0],            // [2]uint256 - commitmentPok (not used)
    input,             // [44]uint256 - public inputs
    nextPubkeys        // bytes[] - 512 pubkeys of 48 bytes each
);
```

## View Functions

```solidity
// Current period
uint256 period = manager.currentPeriod();

// All pubkeys
bytes[] memory allPubkeys = manager.getCurrentSyncCommitteePubkeys();

// Specific pubkey
bytes memory pubkey = manager.getCurrentSyncCommitteePubkey(index);
```

## Admin Functions

```solidity
// Update verifier (owner only)
manager.setVerifierContract(newVerifierAddress);

// Transfer ownership
manager.transferOwnership(newOwner);
```
